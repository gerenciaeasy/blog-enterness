# blog-enterness

Posts publicados do blog de https://enterness.com/blog/.

Este repositório é atualizado automaticamente por uma tarefa agendada a partir do painel do blog.
O site (public_html/blog/_lib.php) lê `posts.json` e `img/` daqui a cada 5 minutos.

Não edite `posts.json` à mão: a próxima sincronização sobrescreve.
